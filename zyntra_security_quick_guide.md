# Zyntra Security Quick Guide (Fictional Demo)

This made-up training guide is for demonstrating the Zyntra Security Analyzer. It is not an official policy and does not describe a real organization.

## If you receive a suspicious message

- Do not open unexpected links or attachments.
- Report the message through your organization's approved security channel.
- Keep the message available so the security team can review its sender and content.
- Verify urgent requests for money, credentials, or one-time codes through a known, separate contact method.

## If you clicked a suspicious link

- Stop interacting with the page and do not enter credentials or payment details.
- Notify your organization's security or IT contact promptly and describe what happened.
- Do not delete the message or try to investigate the link yourself; preserve details for the security team.
- Follow the organization's instructions about disconnecting a device or changing credentials.

## Protect account credentials

- Use a unique password for each important account and store it in an approved password manager.
- Never share a password or one-time sign-in code in response to an unsolicited request.
- If you suspect an account is compromised, contact the official support channel and follow its recovery steps.

## Limitation

This guide is fictional training material. Follow the real organization's incident-response procedures and official security guidance for actual events.
